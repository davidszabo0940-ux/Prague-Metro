# Unity Assets

A rekonstruált Unity projekt assetjeinek helye.

## Tervezett struktúra

- `Scripts/` – C# rekonstrukciós és játéklogikai kód
- `Scenes/` – Unity scene-ek
- `Models/` – 3D modellek
- `Materials/` – anyagok és shaderekhez kapcsolódó assetek
- `Audio/` – hangok
- `Prefabs/` – újrahasznosítható Unity prefabok
- `UI/` – kezelőfelület és kijelzők

Az `Assets/` alatt csak a rekonstruált/újraépített Unity projekt fájljai legyenek. Az eredeti APK-ból kinyert nyers adatok maradjanak a `recovered/` területen.
