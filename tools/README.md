# Tools

A projekt elemzéséhez, kinyeréséhez és konvertálásához használt saját segédprogramok helye.

## Tervezett felosztás

- `extraction/` – APK/XAPK és egyéb források kinyerése
- `analysis/` – DLL, smali és Unity-adatok elemzése
- `conversion/` – exportált vagy rekonstruált adatok átalakítása

A külső, harmadik féltől származó eszközök nem kerülnek ide automatikusan; csak a projekt saját scriptjei és konfigurációi tartoznak ebbe a könyvtárba.
