# Reconstruction documentation

Ez a könyvtár az eredeti Subway Simulator Prague Metro technikai rekonstrukciójának dokumentációja.

## Tartalom

- `game-code-inventory.md` – az APK-ból visszanyert játéklogika és azonosított UnityScript osztályok.
- `status.md` – a rekonstrukció aktuális állapota és a következő vizsgálati lépések.

## Forráselv

A `recovered/` alatt található adatok az eredeti APK/XAPK-ból kinyert vagy abból származó elemzési eredmények. A `reconstructed/` alatt található kód már az újraépítés része.

Az eredeti forráskód nem áll rendelkezésre, ezért minden rekonstruált viselkedést ennek megfelelően kell kezelni: ami nem bizonyítható a visszanyert adatokból vagy az eredeti fejlesztőtől kapott információból, azt nem szabad eredeti implementációként feltüntetni.
