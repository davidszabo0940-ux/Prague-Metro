# Research

Itt kap helyet minden olyan kutatási jegyzet, amely az eredeti játék működésének feltérképezéséhez kapcsolódik, de nem közvetlenül a rekonstrukciós kód dokumentációja.

Példák későbbre:

- eredeti játékverziók és build-azonosítók
- APK/XAPK elemzési jegyzetek
- AssetRipper eredmények
- DLL-elemzés
- Unity serialized objektumok kapcsolatai
- állomás- és útvonalinformációk
- az eredeti fejlesztőtől kapott technikai információk
